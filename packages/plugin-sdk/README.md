# Independent plugin SDK — extraction in progress

This package is **not yet a drop-in replacement** for the public `@hermes/plugin-sdk`: only the exports in `src/index.ts` are implemented. The native host must not switch its alias to this package until the missing public surface, host adapters and acceptance checks are complete. The public package name is reserved here to keep the eventual import specifier unchanged. Runtime React and JSX imports remain external and must resolve to the same singleton as the host.

`installHostServices` supplies host-owned contribution registration, gateway requests, navigation, localization, visibility and other explicitly typed services. The host must mount the exported `queryClient` as its React Query singleton. Missing services fail explicitly. `host.requestProfile` preserves the connection-qualified route and delegates the routing policy to an injected adapter. `Contribute` projects live children and unregisters on unmount. The separate runtime entry installs the same SDK and React namespaces for runtime plugin shims.

Run `npm run build` and `npm test` using the already-installed workspace dependencies. `dist/` is generated and ignored. The esbuild guard rejects resolved files under the legacy desktop renderer, including symlink paths. The host imports `@hermes/plugin-sdk/styles.css` for extracted component styles and supplies the existing theme CSS; component classes and upstream implementations are preserved, not bundled styles.

Source provenance: selected components and utilities, runtime shim and contribution projection derive from `apps/desktop/src` at 1f08da749c65f511667b02eacb5b8ed46a2f8c04. Profile routing and session navigation derive from the same tree. Notices are in LICENSE and UPSTREAM-LICENSE.

Additional compatibility contracts and copied UI/color helpers in this extraction derive from the same baseline: `src/composer-contributions.ts`, `src/compat-contributions.ts`, `src/compat-host.ts`, `src/kanban-contract.ts`, `src/themes/{retint,types}.ts`, `src/lib/{reasoning-effort,text,tool-media-renderers}.ts`, `src/hooks/{use-grab-scroll,use-media-query}.ts`, and `src/ui/{decode-text,status-dot}.tsx`. Host-owned state and operations require the corresponding `PluginHostServices` adapters; their presence in the type surface does not implement native behavior.

The canonical gateway, panel primitives, sandboxed frame, guest document decoder and accent override are derived from the same baseline (`apps/desktop/src/api/{client,canonical-protocol}.ts`, `app/overlays/panel.tsx`, `components/ui/{actions-menu,sandboxed-frame}.tsx`, `lib/browser-guest-document.ts`, `themes/accent-override.ts`). Host `guestFrameShellUrl` must return null for a native frame or an authenticated browser guest shell URL; the shell must implement the baseline preview-document and message relay protocol.
