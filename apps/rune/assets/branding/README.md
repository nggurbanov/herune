# Herune artwork

`logo.png` is the original, unmodified cat-with-headphones artwork supplied by the project owner on
2026-10-31. All PNG icon sizes, ICO and ICNS are format/size conversions of that
image, without redrawing, recoloring or cropping. `social-preview.png` contains
the complete artwork on a 1280×640 canvas for GitHub repository social previews.

Keep this product artwork separate from Hermes agent/bot identities and from the
retained upstream Electron baseline assets. Replacing the product brand must not
change an agent's own avatar.
